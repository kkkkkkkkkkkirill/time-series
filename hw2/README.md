# ДЗ № 2. Прогнозирование продаж

Сравнение **Naive**, **ETS с затухающим трендом** и **градиентного бустинга** для товара `85099B` JUMBO BAG RED RETROSPOT из [UCI Online Retail](https://doi.org/10.24432/C5BW33). Товар, очистка и календарная агрегация взяты из [ДЗ № 1](../hw1/hw1_sales_analysis.ipynb).

**[Открыть выполненный Jupyter Notebook](hw2_sales_forecasting.ipynb)**

## Эксперимент

| Частота | Горизонты, шагов | Продажи | Тестовый хвост | Общих целевых дат |
|---|---|---|---:|---:|
| День | 1, 7, 31, 61 | шт. за день, сетка Вс–Пт | 100 | 40 |
| Неделя | 1, 4, 8 | шт. в пересчёте на 6 рабочих дней | 17 | 10 |
| Месяц | 1, 2 | шт. в пересчёте на 26 рабочих дней | 4 | 3 |

Использовано расширяющееся обучающее окно. Для конкретного прогноза доступны только история к его дате выпуска и календарная сетка. Модели на одной частоте сравниваются на одинаковых целевых датах для всех горизонтов. Неполные крайние периоды исключены. Фактические закрытия не оцениваются, а пропуски для обучения заполняются по прошлым значениям.

**MAE** — основной критерий по ошибке ровно на шаге `h`. **RMSE** сильнее штрафует крупные промахи. **MASE** нормирует MAE исторической наивной ошибкой из первого обучающего окна. **PathMAE** измеряет ошибку по всем шагам от 1 до `h` соответствующих траекторий.

## Лучшие модели по MAE

| Частота | Горизонт | Модель | MAE | RMSE | MASE |
|---|---:|---|---:|---:|---:|
| День | 1 | Gradient Boosting | 127,3 | 214,9 | 0,936 |
| День | 7 | Gradient Boosting | 126,1 | 219,5 | 0,927 |
| День | 31 | Gradient Boosting | 124,5 | 226,2 | 0,915 |
| День | 61 | ETS | 120,3 | 213,1 | 0,884 |
| Неделя | 1 | ETS | 440,2 | 720,8 | 1,053 |
| Неделя | 4 | ETS | 442,2 | 721,0 | 1,057 |
| Неделя | 8 | ETS | 465,6 | 749,6 | 1,113 |
| Месяц | 1 | ETS | 673,6 | 823,9 | 0,828 |
| Месяц | 2 | Naive | 929,7 | 1 138,7 | 1,143 |

- **День.** MAE бустинга почти не меняется, но его RMSE растёт с 214,9 до 230,1 шт. ETS лучше по RMSE на всех дневных горизонтах и по MAE на 61 шаге.
- **Неделя.** ETS выигрывает по MAE на всех трёх горизонтах. Его MAE растёт с 440,2 до 465,6 шт., а результат бустинга приближается к ETS. Все модели недооценили неделю с пиком в 2 693 шт.
- **Месяц.** На 2 шагах Naive выигрывает по MAE последнего шага, ETS — по RMSE и PathMAE. Сравнение основано на трёх целевых месяцах, поэтому небольшая разница MAE чувствительна к отдельным наблюдениям.

## Воспроизведение

Из корня репозитория с Python 3.14:

```bash
python3.14 -m venv hw2/.venv
source hw2/.venv/bin/activate
python -m pip install -r hw2/requirements.txt
cd hw2
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=300 hw2_sales_forecasting.ipynb
```

По умолчанию notebook использует [снимок подготовленных рядов](input/series_85099B.csv). Для повторной подготовки из UCI установите в первой ячейке `REBUILD_FROM_UCI = True`. Загрузчик из ДЗ № 1 использует локальный кэш в `hw1/data` или скачивает исходные данные. Исходные транзакции в репозитории не хранятся.
